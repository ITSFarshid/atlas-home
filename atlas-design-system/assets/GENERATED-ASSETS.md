Generated using the built-in image-generation tool on 27 September 2026, then copied into this project's assets directory. These are illustrative assets for the prototype.

## northbound-portrait.png

Prompt: Create a single square album-cover photograph asset for a premium dark automotive media widget. Original fictional male soul singer, no resemblance to a particular celebrity, closely cropped head and shoulders, contemplative downturned face turned slightly sideways, dark brown skin, dark crew-neck shirt, soft warm side light, muted charcoal studio background, low saturation cinematic editorial photography. Subject mainly on right half, left half darker with negative space for separate UI text. No text, no logos, no interface, no borders. High-quality realistic photography.

## vehicle-overhead.png

Prompt: Single isolated photorealistic 3D product render of an unbranded modern silver graphite compact luxury SUV, orthographic directly overhead plan view, front of car facing exactly top of image. Entire vehicle visible including wing mirrors, panoramic black glass roof, metallic silver panels, realistic restrained studio reflections. Transparent background, no ground, no interface, no text, no circles, no badges, no cast shadow outside the vehicle. Centered, portrait composition.

The returned vehicle image contains a dark studio backdrop despite the transparency request. The component uses a CSS edge mask and blend treatment to integrate it with the near-black surface; the original image remains unchanged.
